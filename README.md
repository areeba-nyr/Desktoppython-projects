# Tic-Tac-Toe Game

A simple terminal-based Tic-Tac-Toe game built in Python. Play against the computer, which makes random moves.

## How to run
```
python tic_tac_toe.py
```

## What I learned building this
- Working with lists to represent game state
- Writing and calling functions with parameters and return values
- Basic game logic and win-condition checking
